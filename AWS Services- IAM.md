IAM- Identity Access Management 

- It is a service that we can grant the permissions and Revoke the permissions for users , Groups and also add the policies
- It controls who can do what inside AWS account
- It is used for security purposes

* Root User- Account owner, Should almost never be used daily
* IAM user- Individual Identity you create ( Can be later added in Group)
* IAM Group- A way to bundle users together & apply the same permissions to all of them
* IAM Roles- Set of permissions that can be temporarily assumed
